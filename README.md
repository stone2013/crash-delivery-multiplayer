## 更新现有 GitHub Pages

只需将本目录中的 index.html 上传到现有 crash-delivery-multiplayer 仓库，替换原来的 index.html，并提交更改。保持原来的 Pages 发布分支及目录。不要把整个解压文件夹作为新的子目录上传，否则访问路径会改变。

等待 Pages 部署完成，再刷新游戏。菜单必须显示「多人 V0.2 · 搭档上岗」。两名玩家都需要更新；V0.1 与 V0.2 不互通。你原有的线上网址不需要更改。本交付包没有自动修改你的 GitHub 仓库。

## 先看模型和动画

主菜单 → 角色 / 动作预览。

01 橙帽、02 蓝帽均为实时绘制的低模 3D 人物。头、躯干、肩肘、髋膝与鞋子分别建模，以父子变换形成关节动画。不是图片贴片，也没有外部模型、贴图或字体文件。

可预览：待机呼吸、走路、抱箱行走、蓄力、投掷、伸手开门、坐姿驾驶、挥手。拖动画面可旋转观察人物。游戏中的拿箱还有短暂的前倾/伸手动作；第一人称袖子颜色与角色配色一致。

## 双人合作

房主点「创建双人房间」，将 6 位房间码或邀请链接发给队友。队友在同一版本中输入房间码并加入。连上后自动开始。

房主默认是 01 橙帽驾驶员；队友默认是 02 蓝帽货箱投递员。两人的输入、位置、视角、手持包裹及动作独立。双方共用一辆快递车、真实货物、门窗破坏状态和订单收入。

驾驶：WASD / 屏幕方向与踏板；B 放砖；V 离开驾驶位。
货箱：WASD / 左下摇杆；拖动画面观察；E 拿箱或互动；G 开关后门；F 辅助瞄准；按住空格或投掷按钮蓄力，松开扔出；R 放下。
T /「看队友」：驾驶员切换货箱内观察视角，仍然保留驾驶控制。再次点击返回路面。
H /「挥手」：触发可被队友看见的挥手动作。

换人驾驶：先停车，当前驾驶员 V 离座。另一人走到货箱前方，E / V 接管空座位。房主统一判定座位占用，不能抢走有人坐着的驾驶位。

暂停：任一方暂停会冻结共同世界；两人都可请求继续。房主切换后台时会触发暂停，避免车辆继续失控。救援和重新开始由房主执行。暂停菜单可退出联机。

## 网络与版本边界

单人测试、模型和动作预览可以离线运行。多人连接需要互联网及 PeerJS 信令服务；本版延用 PeerJS 1.5.5，通过 CDN 按需加载，提供第二下载源。CDN 加载失败不会阻止单人模式和人物预览。

游戏前端可以继续放在 GitHub Pages，但这不代表全部联机基础设施都由 GitHub 提供。实际多人数据使用 WebRTC，房间连接使用 PeerJS 信令。部分网络需要 TURN 中继，不能保证在所有运营商或 NAT 环境下直接连通。本包不包含用户的服务密钥，也没有绑定额外付费服务。自备信令/ICE 配置可通过页面启动前的 window.CRASH_NETWORK_CONFIG 设置。

本版最多 2 人。房主浏览器负责共同世界的物理与事件判定；客人发送输入和动作请求，接收约 20Hz 快照。客人本地预测走动并平滑显示快照，不独立裁定包裹归属、破窗或计分。房主关闭页面会结束连接；未实现房主迁移或断线自动续局。

人物仍受车厢边界限制，未增加下车自由行走或人物间推挤碰撞。此版本面向好友合作原型，没有账号、匹配大厅或竞技级反作弊。6 位房间码不是账号密码。

## 检查范围

已做 Chromium 实际 WebGL 渲染检查、桌面界面及 390×844 / 320×640 / 844×390 触控布局检查；8 个预览动作可以切换，记录的页面错误和 WebGL 错误均为 0。

双端功能测试使用两个独立浏览器页面，经本地 JSON 消息回环接入相同游戏网络协议，不是假设第二名玩家存在。验证了独立操作、驾驶位占用、开关后门、拿箱/投掷、真正投进 101 号窗户后的双方 $100 同步、交通车爆炸结果、共同暂停/恢复、换人驾驶及换回、人物动作同步。

这些属于双端应用协议模拟测试，不是跨设备公网 WebRTC 实测。当前执行环境未能完成真实 WebRTC 连接，也未验证公网 PeerJS 信令可达性；需要你和队友在自己的设备与网络上验证。详见测试记录.txt。

index.html 是唯一运行时必需文件，其余文件是说明或许可。原多人 V0.1 文件没有被本包覆盖。
