暴力快递 · 多人 V0.1

使用：
1. 将 index.html 上传到 GitHub 仓库并开启 GitHub Pages。
2. 两台设备都打开同一个 Pages 地址（需要联网）。
3. 玩家 1 点击“创建双人房间”，把 6 位房间码发给玩家 2。
4. 玩家 2 输入房间码并点击“加入”。

V0.1 原型范围：
- 保留 V0.3 单机游戏作为基线。
- PeerJS/WebRTC 双人连接。
- 房主权威世界状态。
- 20Hz 同步车辆、得分、后门、地址完成状态、破坏状态和活动包裹。
- 加入者进入货箱视角并接收房主世界状态。

注意：
- GitHub Pages 只负责前端托管；V0.1 使用 PeerJS 公共信令建立 WebRTC 连接，因此不是“所有联机基础设施都由 GitHub 提供”。
- 公共信令服务不适合正式大规模发布。后续版本应换成自有/可控信令或专用联机后端。
